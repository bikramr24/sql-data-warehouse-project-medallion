# sql-data-warehouse-project-medallion
Building a modern DWH with proper documentation, SQL server, including ETL processes, data modelling and analytics.

The project follows the Medallion Architecture approach to organize data into layered stages for better data quality, transformation, and performance. It is designed to help understand real-world concepts such as data ingestion, transformation, warehouse design, and business analytics in a practical way.

Whether you are learning data engineering or building enterprise-grade analytics systems, this project provides a strong foundation for modern data warehouse development. Note: this is a learner project so might have a few mistakes, it has a mit licence if you want to make relevant charges.
